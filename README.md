# 명조 매트릭스 파티 구성

빌드나 서버 없이 `index.html`을 열거나 GitHub Pages에서 사용할 수 있습니다.

- 캐릭터를 드래그하여 파티에 넣고, 파티 안이나 파티 사이에서 이동·교환합니다.
- 파티 왼쪽 ☰ 핸들을 다른 파티로 드래그하면 순서가 바뀝니다. ↑ / ↓ 버튼으로도 이동할 수 있습니다.
- 파티 번호는 표시 순서대로 자동 변경됩니다. 사용완료 상태와 선택한 회로는 파티와 함께 이동합니다.
- 삭제 위의 **사용완료** 버튼은 다시 누르면 해제됩니다.
- **회로 선택**에서 버프를 선택하면 아이콘 아래에 짧은 표시명이 나타납니다.
- 파티 구성과 보유 설정은 기존과 같이 브라우저에 자동 저장됩니다. 메모장 저장에는 회로와 사용완료 상태도 포함됩니다.

## 시즌 회로 변경

초기 회로는 참고 이미지의 분류만 넣은 예시입니다. 실제 시즌에 맞는 설명을 입력하세요.

### 화면에서 편집

1. 상단 **회로 편집**을 엽니다.
2. 회로 이름, 짧은 표시명, 버프 설명, 아이콘을 수정합니다. 회로 추가·삭제도 가능합니다.
3. **저장**하면 현재 브라우저에만 적용됩니다.
4. 다른 방문자에게도 적용하려면 **설정 파일 다운로드**를 눌러 받은 `circuits.js`로 저장소의 `js/circuits.js`를 교체하고 GitHub에 올립니다. 이 버튼은 현재 편집값도 저장합니다.

### 파일에서 직접 편집

`js/circuits.js`의 `window.MATRIX_CIRCUITS` 배열을 수정합니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 회로 고유값. 기존 선택을 유지하려면 같은 값을 유지합니다. 새 회로는 서로 다른 값을 사용합니다. |
| `name` | 선택창에 표시하는 이름 |
| `shortName` | 파티 아이콘 아래 표시명 (예: 이상, 공용, 조화도, 기본피해) |
| `description` | 시즌별 버프 설명. 줄바꿈은 `\n`으로 입력합니다. |
| `icon` | `status`, `damage`, `harmony`, `general` 중 하나 |

화면에서 저장한 개인 편집값이 있으면 파일 기본값보다 우선합니다. 새로 배포한 파일 내용을 사용하려면 **회로 편집 → 파일 기본값 사용**을 누르세요. 파티 초기화는 회로 설정을 지우지 않습니다.
