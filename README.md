# 명조 매트릭스 파티 구성

빌드나 서버 없이 `index.html`을 열거나 GitHub Pages에서 사용할 수 있습니다.

- 캐릭터를 드래그하여 파티에 넣고, 파티 안이나 파티 사이에서 이동·교환합니다.
- 파티 왼쪽 ☰ 핸들을 다른 파티로 드래그하면 순서가 바뀝니다.
- 파티 번호는 표시 순서대로 자동 변경됩니다. 사용완료 상태와 선택한 회로는 파티와 함께 이동합니다.
- 삭제 위의 **사용완료** 버튼은 다시 누르면 해제됩니다.
- **회로 선택**에서 버프를 선택하면 아이콘 아래에 짧은 표시명이 나타납니다.
- 파티 구성과 보유 설정, 필터 선택은 브라우저에 자동 저장됩니다.
- **미사용**을 켜면 사용 횟수가 남은 캐릭터만 표시합니다. 보유·속성 필터와 함께 사용할 수 있습니다.
- 보유설정 창에서도 선택한 속성을 다시 누르면 ALL로 돌아갑니다.
- 우측 버튼은 **초기화 / 이미지 저장 / 파티 추가 / 보유설정** 순서입니다. 이미지 저장은 파티 구성을 PNG로 내려받습니다.

## 시즌 회로 변경

회로 설명은 제공된 인게임 이미지를 기준으로 입력되어 있습니다. 시즌 변경 시 아래 파일에서 갱신하세요. 선택창은 공용 → 이상 → 기본피해 → 조화도 순서로 가로 배치되며, 좁은 화면에서는 가로로 스크롤할 수 있습니다.

### 파일에서 직접 편집

`js/circuits.js`의 `window.MATRIX_CIRCUITS` 배열을 수정합니다.

| 필드 | 의미 |
| --- | --- |
| `id` | 회로 고유값. 기존 선택을 유지하려면 같은 값을 유지합니다. 새 회로는 서로 다른 값을 사용합니다. |
| `name` | 선택창에 표시하는 이름 |
| `shortName` | 파티 아이콘 아래 표시명 (예: 이상, 공용, 조화도, 기본피해) |
| `description` | 시즌별 버프 설명. 줄바꿈은 `\n`으로 입력합니다. |
| `icon` | `status`, `damage`, `harmony`, `general` 중 하나 |

회로 목록은 항상 `js/circuits.js`의 값을 사용합니다. 이전 버전에서 브라우저에 저장한 회로 편집값은 적용하지 않습니다. 파일을 수정해 GitHub에 올린 뒤 페이지를 새로고침하면 반영됩니다.

## 화면 배치

PC에서는 캐릭터 목록을 좁게, 파티 영역을 넓게 표시하며 파티 영역이 1120px 이상이면 2열, 그보다 좁으면 1열로 배치합니다. 상단 작업 버튼은 작은 크기로 오른쪽에 정렬합니다. 1000px 이하에서는 목록과 파티를 위아래로 배치하고, 640px 이하에서는 파티의 캐릭터 3칸 아래에 회로 선택과 사용완료·삭제 버튼을 배치합니다.
